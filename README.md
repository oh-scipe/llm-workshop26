# SCIPE Workshop on Large Language Models

If you joined the workshop and want to revisit the material, this repository is the easiest place to start. It brings together the hands-on notebooks, the workshop site, and the background material shared around the event.

The main workshop website is here:

[https://oh-scipe.github.io/llm-workshop26/](https://oh-scipe.github.io/llm-workshop26/)

If you want to review the foundations, browse extra tutorials, or fill in anything you missed, the "Getting Ready" page is still a good place to spend some time:

[https://oh-scipe.github.io/llm-workshop26/getting-ready.html](https://oh-scipe.github.io/llm-workshop26/getting-ready.html)

## Where to look in this repo

Most of the hands-on material lives in [tutorials/](tutorials/).

- [tutorials/day1/](tutorials/day1/) includes the Day 1 notebooks on Gemini and Hugging Face inference.
- [tutorials/day2/](tutorials/day2/) includes notes on model efficiency and tool calling.
- [tutorials/day2/RAG/](tutorials/day2/RAG/) walks through the RAG exercises step by step, from collecting papers to querying a vector database.
- [tutorials/day3/README.md](tutorials/day3/README.md) points to the Day 3 research roadmap discussion.

Most of these files are Jupyter notebooks (`.ipynb`), so they are easiest to revisit in Jupyter or Google Colab.

## A good way to use this material

If you are coming back to the workshop after a few weeks, start with the website to refresh your memory, then open the notebook from the day you want to review. Day 1 is a good reset if you want the big picture again. Day 2 is the place to go if you want more practice with tool use or RAG. The getting-ready page is useful any time you want a slower introduction or want to branch out into related tutorials and courses.

This repository is not meant to be a polished software package. It is a working collection of workshop material you can return to, rerun, and adapt for your own learning.
